# MT-001 Runtime Cloud System AEP v0.1

This is an example AEP package for the Moodify Runtime cloud execution node.

Read in order:

1. `manifest.json`
2. `agent_spec.md`
3. `rules.md`
4. `task_map.yaml`
5. `tasks/MT-001-T00_Runtime_Node_Protocol.md`
6. `validation/acceptance_criteria.md`

All generated results must be written to `outputs/` or `reports/`.
