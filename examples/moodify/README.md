# Moodify AEP-NEM Examples

This directory contains example AEP and NEM documents for applying the AEP-NEM protocol to the **Moodify** project.

In this protocol context, Moodify is modeled as an AI music post-processing engineering organism. Its goal is to move AI-generated music from virtual sound waves toward more realistic sound waves through runtime processing, scoring, presets, reports, and desktop workflows.

## Contents

| File | Type | Description |
|---|---|---|
| `aep_example_runtime_smoke_test.md` | AEP | Minimum Runtime audio processing smoke test |
| `aep_example_mrs_validation.md` | AEP | MRS scoring validation against a fixed sample set |
| `nem_example_mrs_open_benchmark.md` | NEM | Evolvable MRS benchmark node |
| `nem_example_electron_desktop_app.md` | NEM | Evolvable Electron desktop app node |

## Relationship

- `docs/aep-nem/` defines the protocol language and reusable templates.
- `schemas/` provides machine-readable validation drafts.
- `examples/moodify/` shows how the protocol can be applied to one real project.

Moodify is a protocol **application**, not the protocol itself.
